# DreamCode Notes

A simple and elegant Android application for managing your personal notes.

## Features
- **Create Notes**: Quickly jot down your thoughts and ideas.
- **View Notes**: A clean list view of all your saved notes.
- **Edit Notes**: Update your notes whenever you need.
- **Delete Notes**: Easily remove notes you no longer need.
- **Modern UI**: Styled with DreamCode branding and a user-friendly interface.

## Technologies Used
- **Language**: Java
- **Database**: Room Persistence Library for local data storage.
- **Architecture**: MVVM with LiveData.
- **Navigation**: Jetpack Navigation Component.
- **UI**: Material Design 3.
